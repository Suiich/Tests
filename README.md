部分学生反应学校自编题库质量低下，难以通过做题来检测知识点掌握度，所以尝试做了这个刷题系统，目前只有口腔医学的题目。

后续可能会更新吧，如果同学反响良好的话，因为确实没有什么技术含量，只要把知识点整理好就能自己搓一个。

## 安装


*有问题多用ai，查一下就知道怎么装了*


需要 Python 3.9 及以上。推荐用 [pipx](https://pipx.pypa.io/) 安装（会自动放进独立环境并把命令加到 PATH）：

```bash
pipx install git+https://github.com/Suiich/Tests.git
```

也可以直接用 pip：

```bash
pip install git+https://github.com/Suiich/Tests.git
```

更新到最新题库：

```bash
pipx upgrade oral-quiz
# 或
pip install --upgrade git+https://github.com/Suiich/Tests.git
```

## 使用

在终端输入：

```bash
exercise_enter
```

先选章节（`0` 为总章，`1`–`13` 为各章），再选级别：

| 序号 | 级别 | 内容 |
|---|---|---|
| 0 | 随机 | 所选范围内的全部题目 |
| 1 | I 级 | 旧题，基础知识点单选 |
| 2 | II 级 | 新题，强调鉴别的单选 |
| 3 | III 级 | 排序题 |
| 4 | IV 级 | 多选题，不提示正确项数 |

- 总章选好级别后再输入抽题数量（默认 30 题，可输入数量或 `all`）
- 单选输入一个字母；多选输入全部正确字母，如 `ACD`；排序按顺序连写全部字母，如 `BADC`
- 字母也可以换成序号，如 `134`
- 输入 `q` 返回上一级，任何时候输入 `exercise_exit` 退出

每题作答后显示正确答案、解析和出处；每轮结束显示得分和错题回顾。题目和选项顺序每次随机打乱。

## 题库格式与贡献

题库在 `src/oral_quiz/questions/`，每章一个 JSON 文件：

```json
{
  "id": "ch04-001",
  "section": "龋病",
  "question": "题干",
  "options": ["选项一", "选项二", "选项三"],
  "answer": 0,
  "source": "笔记原文",
  "explanation": "解析"
}
```

上面是基础单选题，`answer` 是正确选项的下标。不写 `type` 时按单选处理，不写 `level` 时属于 I 级。

新题增加 `type` 和 `level` 两个字段，每题最多 8 个选项：

| 题型 | `type` | `level` | `answer` |
|---|---|---|---|
| 单选 | `single` | 1 或 2 | 正确选项的下标，如 `2` |
| 排序 | `order` | 3 | 按正确顺序排列的下标，如 `[0, 1, 2, 3]` |
| 多选 | `multi` | 4 | 全部正确选项的下标，如 `[0, 2, 3]` |

发现错题欢迎提 Issue 或 PR。

想用自己的题库，可以把 `ch*.json` 放进一个文件夹，然后：

```bash
ORAL_QUIZ_DIR=/path/to/my_questions exercise_enter
```
